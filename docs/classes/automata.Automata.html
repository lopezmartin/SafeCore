      Validate the probabilities of the transitions in the automaton.

      This function validates the probabilities of the transitions in the given PTAModel. It performs detailed checks on the probabilities, including sum checks and normalization.

      Parameters

      • model: PTAModel

        The PTAModel to validate.

      • options: { autoNormalize?: boolean; tolerance?: number } = {}

        Optional options for the validation.

        • OptionalautoNormalize?: boolean

          Flag indicating whether to automatically normalize the probabilities. Default is false.

        • Optionaltolerance?: number

          The tolerance for the probability sum check. Default is 1e-6.

      Returns { errors: string[]; ok: boolean; warnings: string[] }

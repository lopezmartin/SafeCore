# SafeCore
SafeCore is a runtime framework for probabilistic timed automata that validates model structure (Zod), enforces domain rules (probabilities, guards, resets) and embeds an integrated LTL/PCTL model checker. It verifies dynamically generated models in‑process, improving safety, traceability and early error detection.
